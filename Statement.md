# Library Management System
## Problem Statement
The manual maintenance of book and library member records can be time-consuming and error-prone.
The Library Management System is a simple command-line utility for managing books, library members and basic issue and return operations.
The primary objective of the project is to simplify common library management tasks using a Java utility.
---
## Scope of the Project
The project is focused on basic operations required in a small library.
The system includes the following functionality:
Add books
View books
Search for books
Remove books
Register library members
View members
Search for members
Issue books
Return books
View issued books
Generate a basic library report
The current project is limited to a command-line environment and does not include advanced features such as online accounts, payment processing or database connectivity.
---
## Target Users
The main target users of the system are:
Library staff
Students
Small library administrators
---
## High-Level Features
The main features of the project are:
1. Book Management
Add, view, search and remove books.
2. Member Management
Register and search library members.
3. Issue and Return Management
Issue available books, return issued books and view books currently on loan.
4. Library Reporting
Generate a report showing total books, available books, issued books and total members.
5. Input Validation
Check basic user inputs and handle invalid operations.
6. File Handling
Save basic book information using a text file.
